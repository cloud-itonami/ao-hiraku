# kotoba によるエンパワーメント・プロセス（ao-hiraku 設計）

日付: 2026-10-07 / 状態: R0（bot 稼働・公開は人間レビュー後）

## 1. 何の格差を埋めるのか

格差の多くは「能力の差」ではなく **情報と経路の差** として現れる。

| 軸 | 届かない理由の例 | 埋め方の例 |
|---|---|---|
| 性別 | 「女子は理系に向かない」「男なのに保育？」という周囲の固定観念、ロールモデル不在 | 多様なロールモデル教材、進路の選択肢を具体的に見せる |
| 地域 | 塾・大学・企業・博物館が近くにない、相談できる大人が少ない | オンライン無料講座、遠隔の相談窓口、地方在住者向け支援制度 |
| 年齢 | 子ども：制度を自分で調べられない / 若者：学校を出た後の支援が見えない | 年代別に言い換えた案内、18歳以降の制度（奨学金・サポステ等） |
| 文化・言語 | 日本語が母語でない子と保護者、外国ルーツ、制度の前提知識がない | やさしい日本語・ルビ・多言語、制度の背景説明 |
| 障害 | 情報がアクセシブルでない、合理的配慮を知らない | 読み上げ前提の構成、合理的配慮・支援窓口の案内 |
| 経済 | 無料のものがあることを知らない、費用で諦める | 無料・給付型を優先表示、修学支援制度・奨学金の案内 |
| 家庭環境 | ヤングケアラー、ひとり親、虐待・不登校、相談できる家族がいない | 匿名で使える窓口、学校外の学びの場 |

## 2. プロセス（5 段）

```
 気づく ─→ つなぐ ─→ まなぶ ─→ ためす ─→ ひろげる
(格差マップ) (道しるべ)  (教材)   (小さな一歩) (共有・還元)
 michishirube  soudan    kyozai    soudan      social-capital(将来)
```

1. **気づく** — `hiraku-michishirube` が格差軸 × 年代のマトリクスでカタログの薄いところを毎日測る。
   「誰に届いていないか」を数字で見える化する（届いていない = カタログが空 / URL が死んでいる / 未検証）。
2. **つなぐ** — `hiraku-soudan` が相談内容から該当セルを引き、**根拠のある**（カタログに載っている）リソースだけを案内する。
   作り話の制度・電話番号を出さないことを最優先。
3. **まなぶ** — `hiraku-kyozai` が kotoba LLM で教材を起こす。やさしい日本語・ルビ・多言語・年代別。
   既存資産（青空文庫 aozora、hyakka、NHK for School 等）への導線を必ずつける。
4. **ためす** — 教材と相談の最後に「今日できる小さな一歩」を 1 つだけ提案する。
   ミッション化・ポイント化はしない（manabi master G3: no streaks / badges / XP / FOMO を継承）。
5. **ひろげる** — 学んだ人が次の人に伝える。将来 `ao-social-capital` の台帳に、本人の明示同意のもとで接続する（R2 以降、今は設計のみ）。

## 3. 原則（全 bot の SOUL に共通）

- **本人が主体**：bot は決めない。選択肢と根拠を示し、決めるのは本人。
- **属性を聞き出さない**：性別・国籍・障害・家計などは本人が言った範囲だけ使う。推測で決めつけない。
- **固定観念を再生産しない**：「女の子なのに」「男らしく」「〇〇人だから」型の表現を出力しない（`data/safety.json` で機械検査）。
- **作らない**：制度名・電話番号・URL はカタログにあるものだけ。わからないことは「わからない、ここで確かめられる」と言う。
- **安全網が最優先**：命・虐待・暴力の兆候があれば、他の話より先に緊急窓口（`data/safety.json`）を案内する。
- **個人情報を残さない**：相談内容を台帳に保存しない。台帳に残すのはカタログ・教材のメタ情報だけ。
- **エンゲージメントを測らない**：利用時間・連続日数・DAU を目標にしない。測るのは「カタログの厚み」「教材の品質ゲート通過」「リンクの生存」。
- **公開は人間**：教材の公開、外部チャネル（LINE・Discord 等）への接続、カタログの正式採用は operator の go の後。

## 4. 測る指標（MEASURE-BEFORE-REPORT）

| 指標 | どこで | 意味 |
|---|---|---|
| coverage[axis][stage] | michishirube ledger | セルごとの verified エントリ数。0 のセルが最優先 |
| link-alive ratio | michishirube ledger | 実測で 2xx/3xx を返したエントリ比率 |
| kyozai gate pass / fail | kyozai ledger | 品質ゲートの通過数と落ちた理由 |
| kyozai coverage | kyozai ledger | テーマ × 年代 × 言語のうち ready 教材があるセルの数 |

未実測は UNMEASURED と書く。測れなかったものを成功として報告しない。
